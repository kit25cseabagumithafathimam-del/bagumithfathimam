# Bagumitha Fathima M — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It includes resume details, academic projects, skills, contact information, and a direct CV download.

## Run locally

Open `index.html` in a modern browser. Google Fonts and the illustrative project images load over the internet.

## Files

- `index.html` — semantic page content
- `styles.css` — layout, colors, responsive styles, and print styles
- `script.js` — mobile navigation, scroll effects, and contact form behavior
- `Bagumitha-Fathima-M-Resume.pdf` — downloadable resume

The hero and About sections use the local `profile-photo.jpg` file. Replace that file to update both portraits; keep the relative image paths in `index.html`.

The contact form validates its fields and opens a prefilled email in the visitor's default email app. It does not send messages to a server.
